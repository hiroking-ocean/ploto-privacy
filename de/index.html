Datenschutzerklärung für Ploto

1. Grundsätze

Ploto (nachfolgend „die App“) ist eine Projektmanagement-App für Windows. Zur Nutzung sind weder die Erstellung eines Kontos noch eine Anmeldung erforderlich.

Projekte werden auf dem Gerät oder an einem vom Benutzer gewählten freigegebenen Speicherort abgelegt. Ploto bietet keine eigene Cloud-Synchronisierung und überträgt vom Benutzer eingegebene Projektinhalte wie Aufgaben, Verantwortliche, Zeitpläne, Notizen oder Whiteboards nicht automatisch an die Server des Anbieters.

Die App enthält keine Ploto-eigenen Analyse- oder Telemetriefunktionen, Werbe-SDKs, Verhaltensverfolgung oder automatische Übermittlung von Absturzberichten an externe Dienste.

2. Auf dem Gerät gespeicherte Informationen

Projekte werden als .ploto-Dateien an dem vom Benutzer gewählten Ort gespeichert. Oberflächeneinstellungen, Lizenzschlüssel, zuletzt geöffnete Dateien, der Anzeigestatus von Hinweisen und ähnliche Informationen werden auf dem Gerät gespeichert. Solange ein Projekt geöffnet ist, wird für stabiles Bearbeiten und Speichern eine lokale Arbeitskopie angelegt und beim ordnungsgemäßen Schließen gelöscht.

Um die gleichzeitige Bearbeitung desselben Projekts durch mehrere Personen an einem freigegebenen Ort zu verhindern, wird am Speicherort des Projekts vorübergehend eine Sperrdatei erstellt. Sie enthält den Windows-Benutzernamen, den Computernamen, die Prozess-ID und Zeitangaben und wird beim ordnungsgemäßen Beenden gelöscht.

Ploto verschlüsselt .ploto-Dateien nicht selbst. Wenn Sie vertrauliche Geschäftsinformationen speichern, richten Sie Geräteverschlüsselung, Zugriffs- und Freigaberechte des Speicherorts sowie Sicherungen gemäß den Vorgaben Ihrer Organisation ein. Einzelheiten zu Speicherorten, Dateinamen und Löschung finden Sie in den technischen Informationen für IT-Abteilungen.

3. Situationen, in denen externe Dienste verwendet werden

Das normale Erstellen, Bearbeiten und Speichern von Projekten ist offline möglich. Wenn der Benutzer eine der folgenden Aktionen auswählt, verarbeitet der jeweilige externe Dienst die erforderlichen Informationen.

3.1. Microsoft Store und Windows

Der Microsoft Store verarbeitet die Verteilung, Aktualisierung, Käufe im Store und Rezensionen. Abhängig von den Geräte- und Organisationseinstellungen können Windows und der Microsoft Store Installations- und Absturzinformationen sowie Diagnoseinformationen zum Betriebssystem und Gerät verarbeiten. Der Anbieter von Ploto kann zusammengefasste Informationen, die keine Person direkt identifizieren, zur Qualitätsverbesserung verwenden. Es gilt die Datenschutzerklärung von Microsoft.

3.2. Webkauf einer Pro-Lizenz

Bei einem Webkauf verarbeitet Stripe die E-Mail-Adresse des Käufers, Zahlungsmethode, Produkt, Betrag, Währung, Datum und Uhrzeit sowie Verbindungsinformationen. Vertrauliche Zahlungsdaten wie Kartennummern werden direkt von Stripe verarbeitet und von den Servern des Ploto-Anbieters weder erfasst noch gespeichert.

Zur Ausstellung einer gerätegebundenen Lizenz erzeugt die App zu Beginn des Kaufs auf dem Gerät aus einem von Windows für den Herausgeber bereitgestellten Gerätekennwert einen Ploto-spezifischen Einweg-Hash und übermittelt ihn an Stripe. Der ursprüngliche Gerätekennwert wird nicht übertragen. Ein auf Vercel ausgeführter Prozess stellt den Lizenzschlüssel aus, und Resend sendet ihn an die E-Mail-Adresse des Käufers. Nach dem Kauf wird die Lizenz auf dem Gerät überprüft.

Es gelten jeweils die Datenschutzerklärung von Stripe, der Datenschutzhinweis von Vercel und die Datenschutzerklärung von Resend.

3.3. Kontakt und optionale Formulare

Wenn der Benutzer eine Kontakt-E-Mail oder ein Google-Forms-Formular absendet, werden die eingegebenen Inhalte und die optionale E-Mail-Adresse für Antworten, Support, Fehleruntersuchung und Qualitätsverbesserung verwendet. Die App hängt Projektinhalte nicht automatisch an und übermittelt sie nicht. Senden Sie ohne Genehmigung Ihrer Organisation keine vertraulichen Informationen, personenbezogenen Daten, Projektdateien oder Bildschirmaufnahmen. Es gilt die Datenschutzerklärung von Google.

3.4. Aufruf der offiziellen Website und dieser Erklärung

Die offizielle Website ploto-app.com wird über GitHub Pages bereitgestellt und verwendet Google Analytics 4. Wird die offizielle Website mit ?ga=off geöffnet, speichert der Browser eine Einstellung, durch die das Analyse-Tag nicht geladen wird.

Diese Erklärung wird über GitHub Pages unter hiroking-ocean.github.io bereitgestellt. Auf dieser Seite ist keine Ploto-eigene Zugriffsanalyse eingerichtet, und sie lädt keine externen Webfonts. GitHub kann übliche Zugriffsinformationen verarbeiten. Diese Seite speichert im Browser ausschließlich die gewählte Darstellung und Sprache. Es gilt die Allgemeine Datenschutzerklärung von GitHub.
