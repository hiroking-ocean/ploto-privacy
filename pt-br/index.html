1. Introdução

O Ploto ("o Aplicativo") é um software de gerenciamento de projetos para Windows. Ele inclui gráficos de Gantt, quadros Kanban, matrizes de prioridade, visualizações por membro, notas e quadros brancos, todos projetados para manter o controle absoluto dos dados nas mãos do usuário.

Esta Política de Privacidade descreve como os dados são tratados. Em resumo: o Ploto não coleta dados pessoais e não envia seus projetos para servidores remotos.

2. Informações Coletadas

Nenhuma.

O Ploto não coleta, armazena, transmite ou vende dados pessoais como nomes, e-mails, endereços IP, localizações, identificadores de dispositivo ou conteúdos de projetos.

O Aplicativo não contém bibliotecas de análise (ex: Google Analytics), telemetria, relatórios automáticos de falhas ou rastreamento publicitário. Não é necessário criar uma conta para utilizá-lo.

3. Armazenamento e Gestão de Dados

Todos os projetos, tarefas, cronogramas, quadros Kanban, matrizes, notas, ToDos e modelos (.ploto-pack) são armazenados localmente no seu dispositivo ou em um local de rede compartilhado que você definir, no formato de banco de dados SQLite .ploto.

Seus arquivos nunca saem do seu ambiente, a menos que você decida movê-los ou compartilhá-los. O desenvolvedor não possui servidores para receber ou processar seus dados.

4. Uso de Rede e Serviços Externos

O Ploto opera completamente offline e não transmite dados de projetos pela rede. As seguintes integrações com serviços externos existem apenas para finalidades específicas:

4.1. Microsoft Store (Distribuição e Atualizações)

A distribuição, atualização e compras no Microsoft Store são regidas pela Declaração de Privacidade da Microsoft.

4.2. Licenças Pro e Pagamentos (Stripe)

Ao adquirir uma licença no site oficial, o pagamento é processado com segurança pela Stripe. O desenvolvedor não recebe nem armazena números de cartão de crédito.

A verificação da licença ocorre inteiramente offline por meio de assinaturas criptográficas Ed25519. Nenhum dado de telemetria ou dispositivo é enviado a servidores. O aplicativo funciona normalmente em redes corporativas isoladas.

4.3. Feedback e Pesquisas Opcionais (Google Forms)

Ao clicar em "Comentários e erros" no menu Ajuda ou na Tela Inicial, o navegador web padrão abrirá uma página do Google Forms.

A participação é totalmente voluntária. Apenas os dados que você preencher serão enviados ao desenvolvedor via Google, conforme a Política de Privacidade do Google.

5. Compartilhamento com Terceiros

Como não coletamos nem mantemos informações pessoais ou de projetos, nenhum dado é vendido, compartilhado ou alugado para terceiros.

6. Privacidade de Menores

O Ploto não coleta intencionalmente dados pessoais de menores. O aplicativo é seguro para usuários de todas as idades.

7. Alterações nesta Política

Quaisquer alterações serão publicadas nesta página com uma data de atualização revisada.
