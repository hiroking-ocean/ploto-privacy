データ主権はお手元に。徹底したローカルファースト設計

Ploto は、すべての処理をユーザーご自身の端末内で行うデスクトップアプリです。個人データの収集・送信・販売は行わず、プロジェクト情報は完全にユーザーの管理下に留まります。

データ収集ゼロ（アプリ本体）

アカウント登録不要。アプリ本体にはアナリティクス、テレメトリ、クラッシュリポーター、広告トラッキング等は一切含まれていません（※OS/Store標準の診断情報を除く）。

完全ローカル保存

すべてのプロジェクト・タスク・ToDo・設定は、端末内のローカルファイル（SQLite）またはご自身が指定した社内共有先にのみ保存されます。

オフライン署名認証

Pro版ライセンス認証は端末内の Ed25519 暗号署名検証で完結。外部サーバーへの通信不要で閉域網でも動作します。

透明な外部連携

Microsoft Store / Windows プラットフォーム診断、Stripe 決済、Google Forms アンケート等の外部サービスとの関わりを明確に開示しています。

1. はじめに

Ploto（以下「本アプリ」）は、Windows デスクトップ環境で動作するプロジェクト管理アプリケーションです。ガントチャート、カンバン、優先度マトリクス、メンバー別タスク、ノート、ホワイトボードなどの多彩なビューを提供しながら、すべてのデータをユーザー自身の手元で安全に管理できるように設計されています。

本プライバシーポリシーでは、本アプリにおけるデータのお取り扱いについて詳しく説明します。結論として、本アプリがユーザーの個人データやプロジェクト情報を秘密裏に収集したり、外部サーバーへ送信したりすることは一切ありません。

2. 収集する情報

アプリ本体による個人データの収集は一切ありません。

本アプリは、ユーザーの氏名、メールアドレス、IPアドレス、位置情報、デバイス識別子、タスクの内容などの個人データを一切収集、記録、送信、販売しません。

本アプリには、アクセス解析ツール（Google Analytics等）、利用動向のテレメトリ収集、自動クラッシュリポーター、広告SDK、行動トラッキング等の追跡プログラムは一切組み込まれていません。また、アプリの利用開始にあたってアカウントの作成やログインを求められることもありません。

※なお、Windows OS および Microsoft Store プラットフォームが標準機能として自動収集する診断データ（クラッシュログやインストール集計など）については、第4.1項をご確認ください。

3. データの保存と管理

作成されたプロジェクト、タスク、ガントチャート、カンバン、優先度マトリクス、メンバー別タスク、ノート、ホワイトボード、ToDo、設定、およびカスタムテンプレート（.ploto-pack）などの全データは、すべてお使いの端末内、またはユーザーご自身が明示的に保存先に指定した共有場所（社内ファイルサーバーやネットワークドライブ等）に .ploto 形式（SQLite データベース）で保存されます。

これらのファイルは、ユーザー自身が移動や共有の操作を行わない限り、端末の外に出ることはありません。開発者（当方）は、ユーザーのデータを受信、保存、閲覧、または処理するサーバーを一切保有・運用していません。

4. ネットワーク利用と外部サービス

Ploto は完全オフライン環境で動作するよう設計されており、プロジェクトデータをネットワーク経由で送信することはありません。ただし、プラットフォーム機能やユーザーが自発的に選択する機能において、以下の外部サービスと関わりがあります。

4.1. Microsoft Store および Windows によるプラットフォーム診断データ

本アプリの配布、自動更新、および Microsoft Store 経由のアプリ内アドオン購入は、Microsoft Store プラットフォームを通じて行われます。これらに伴い、Windows OS および Microsoft Store は、OS レベルの標準機能（Windows Error Reporting 等）として以下の診断データや利用統計を自動的に収集する場合があります：

・アプリのインストール、更新、アンインストールなどの配信イベント

・アプリが異常終了（クラッシュ）または応答停止（ハング）した際のエラーログやスタックトレース

・集計されたOSバージョン、デバイスアーキテクチャ、大まかな地域情報

これらは Ploto アプリ独自の実装によって収集されるものではなく、Windows プラットフォームによって収集・管理されます。開発者は、Microsoft Partner Center の管理画面を通じて、個人を特定できない「集計された統計情報（クラッシュ発生率や総利用デバイス数など）」としてのみこれらを閲覧し、アプリの品質向上や不具合修正のために利用します。ユーザーのプロジェクトデータやタスクの内容が Microsoft や開発者に送信されることはありません。これらには Microsoft のプライバシーに関する声明 が適用されます。

4.2. 有料ライセンス（Pro版）と決済（Stripe）

公式Webサイト経由で Pro 版ライセンスをご購入いただく場合、決済処理は米 Stripe 社のセキュアな決済基盤を通じて行われます。開発者がユーザーのクレジットカード番号等の機密決済情報を直接取得・保持することはありません。

ご購入後に発行されるライセンスキーの認証は、アプリ内のオフライン暗号署名検証（Ed25519） により端末内で完結します。ライセンス認証のために端末の識別情報や通信ログを開発者のサーバーへ送信することはありません。インターネットに接続されていない閉域環境でも問題なくご利用いただけます。

4.3. 任意のフィードバック・アンケート（Google Forms）

本アプリのヘルプメニューや起動画面から「ご意見・不具合報告」を選択した場合、お使いのシステムの既定Webブラウザが起動し、Google Forms のアンケートページが開きます。

回答の送信や連絡先メールアドレスの入力は完全に任意であり、ユーザーがフォーム上で直接入力した内容のみが Google 社のサーバーを経由して開発者に届きます。これには Google プライバシー ポリシー が適用されます。アプリがバックグラウンドで無断送信することはありません。

5. 第三者への情報提供

当方はユーザーのプロジェクトデータや個人情報を収集・保有しないため、第三者へ販売、共有、貸与、提供することはあり得ません。

6. 子どものプライバシー

Ploto は、子どもを含むいかなる方からも意図的に個人情報を収集することはありません。すべての機能は年齢を問わず安全にご利用いただけます。

7. 本ポリシーの変更

本プライバシーポリシーを変更する場合は、本Webページ上に新しい「最終更新日」とともに改訂版を掲載します。重要な変更がある場合には、アプリ内のリリースノート等でも告知します。
