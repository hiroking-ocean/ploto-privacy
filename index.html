1. 基本方針

Ploto（以下「本アプリ」）は、Windows 向けのプロジェクト管理アプリです。本アプリの利用にアカウント作成やログインは必要ありません。

プロジェクトは利用者が指定した端末内または共有場所に保存されます。Ploto 独自のクラウド同期機能はなく、利用者が入力したタスク、担当者、日程、ノート、ホワイトボード等のプロジェクト内容を、Ploto 提供者のサーバーへ自動送信する機能はありません。

アプリ本体には、Ploto 独自のアナリティクス、テレメトリ、広告SDK、行動トラッキングまたは外部の自動クラッシュ送信機能を組み込んでいません。

2. 端末内に保存する情報

プロジェクトは .ploto ファイルとして、利用者が選んだ場所に保存します。画面設定、ライセンスキー、最近開いたファイル、案内の表示状態等は端末内に保存します。プロジェクトを開いている間は、安定して編集・保存するため端末内に作業コピーを作成し、正常に閉じたときに削除します。

共有場所で同じプロジェクトを複数人が同時編集することを防ぐため、プロジェクトと同じ場所に一時的なロックファイルを作成します。このファイルには Windows のユーザー名、コンピューター名、プロセスIDおよび時刻が含まれ、正常終了時に削除されます。

.ploto ファイルには Ploto 独自の暗号化を施していません。業務上の機密情報を保存する場合は、端末暗号化、保存先のアクセス権、共有権限およびバックアップを利用組織の規程に従って設定してください。保存場所・ファイル名・削除方法等の詳細は、情報システム部門向け技術情報で確認できます。

3. 外部サービスを利用する場面

通常のプロジェクト作成・編集・保存はオフラインで行えます。次の操作を利用者が選んだ場合、外部サービスが必要な情報を処理します。

3.1. Microsoft Store・Windows

アプリの配布、更新、Store内購入およびレビューは Microsoft Store が処理します。Windows や Microsoft Store は、端末・組織の設定に応じて、インストール情報、クラッシュ情報、OS・端末に関する診断情報等を処理する場合があります。Ploto 提供者は、個人を直接特定しない集計情報を品質改善に利用する場合があります。Microsoft のプライバシーに関する声明 が適用されます。

3.2. Web経由の Pro ライセンス購入

Web購入では Stripe が、購入者のメールアドレス、決済手段、購入商品、金額、通貨、日時および接続情報を処理します。カード番号等の機密な決済情報は Stripe が直接処理し、Ploto 提供者のサーバーでは取得・保存しません。

端末紐付けライセンスを発行するため、購入開始時に Windows の発行者向け端末識別値から Ploto 専用の一方向ハッシュを端末内で生成し、Stripe へ送信します。元の端末識別値は送信しません。Vercel 上の処理がライセンスキーを発行し、Resend が購入者のメールアドレスへ送信します。購入後のライセンス確認は端末内で行われます。

Stripe プライバシーポリシー、Vercel Privacy Notice、Resend Privacy Policy がそれぞれ適用されます。

3.3. 問い合わせ・任意のフォーム

利用者が問い合わせメールまたは Google Forms を送信した場合、入力した内容と任意のメールアドレスを、回答、サポート、不具合調査および品質改善のために利用します。本アプリがプロジェクト内容を自動添付・送信することはありません。組織の許可なく秘密情報、個人情報、プロジェクトファイルまたは画面キャプチャを送信しないでください。Google プライバシー ポリシー が適用されます。

3.4. 公式サイト・本ポリシーの閲覧

公式サイト ploto-app.com は GitHub Pages で配信し、Google Analytics 4 を利用します。公式サイトを ?ga=off 付きで開くと、そのブラウザでは計測タグを読み込まない設定を保存します。

本ポリシーは hiroking-ocean.github.io の GitHub Pages で配信します。本ページには Ploto 独自のアクセス解析を設置せず、外部Webフォントを読み込みません。GitHub が通常のアクセス情報を処理する場合があります。本ページがブラウザに保存するのはテーマと表示言語の選択です。GitHub General Privacy Statement が適用されます。

4. 利用目的・第三者による処理

Ploto 提供者が購入、問い合わせ、任意フォーム等を通じて受け取る情報は、ライセンスの発行・再送・端末紐付け、不正利用防止、決済・サポート対応、不具合調査、品質改善、会計・税務・紛争対応その他の法令遵守に必要な範囲で利用します。

プロジェクトデータ、購入者情報または問い合わせ情報を販売、貸与、広告配信またはデータブローカーへの提供に利用しません。配布、購入、ライセンス発行、メール送信、フォーム送信およびWeb閲覧のため、必要な範囲で Microsoft、Stripe、Vercel、Resend、Google および GitHub が情報を処理します。各社の方針に従い、日本国外を含む国・地域で処理または保存される場合があります。

法令に基づく場合、人の生命・身体・財産の保護に必要な場合、または権利保護・不正防止に必要な場合は、適用法令の範囲で関係機関等へ情報を開示することがあります。

5. 保存期間・削除・確認等の請求

購入・ライセンス情報は、ライセンスの再表示・再送、購入サポート、不正防止、会計・税務その他の法令遵守に必要な期間保持します。問い合わせ・フォーム回答は、回答、調査、品質改善および法令遵守に必要な期間保持します。外部事業者が独自目的で保持する情報の期間は各社の方針に従います。

利用者が保存したプロジェクト等は、利用者が削除するまで残ります。アプリをアンインストールしても、利用者が選択した保存先のファイルと一部の端末内補助ファイルは残ります。完全な削除方法は、情報システム部門向け技術情報を確認してください。

Ploto 提供者が保有する購入者情報、問い合わせ情報等の確認、訂正、利用停止または削除を希望する場合は、下記の連絡先へ請求してください。本人確認のうえ、法令上または取引・ライセンス記録上保持が必要な情報を除き、合理的な範囲で対応します。プロジェクト内容は提供者が保有しないため、提供者側での開示・復元・削除はできません。
