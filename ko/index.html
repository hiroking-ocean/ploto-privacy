Ploto 개인정보 처리방침

Ploto는 사용자가 지정한 위치에 프로젝트를 저장하는 Windows 앱입니다. 일반적인 사용에는 계정이나 인터넷 연결이 필요하지 않으며 프로젝트 내용을 Ploto 제공자의 서버로 자동 전송하지 않습니다.

최종 수정일: 2026-09-03
문의: hiroki.lab@outlook.com

정보시스템 부서의 도입 심사를 위해 실행 권한, 저장 위치, 통신 대상, 암호화 등을 정리한 기술 정보를 공개하고 있습니다.

1. 기본 방침

Ploto(이하 「본 앱」)는 Windows용 프로젝트 관리 앱입니다. 본 앱을 사용하는 데 계정 생성이나 로그인이 필요하지 않습니다.

프로젝트는 사용자가 지정한 단말 또는 공유 위치에 저장됩니다. Ploto 자체 클라우드 동기화 기능은 없으며, 사용자가 입력한 작업, 담당자, 일정, 노트, 화이트보드 등의 프로젝트 내용을 Ploto 제공자의 서버로 자동 전송하는 기능도 없습니다.

앱 자체에는 Ploto 고유의 분석, 텔레메트리, 광고 SDK, 행동 추적 또는 외부 자동 오류 보고 기능을 포함하지 않습니다.

2. 단말에 저장되는 정보

프로젝트는 사용자가 선택한 위치에 .ploto 파일로 저장됩니다. 화면 설정, 라이선스 키, 최근에 연 파일, 안내 표시 상태 등은 단말에 저장됩니다. 프로젝트가 열려 있는 동안에는 안정적인 편집과 저장을 위해 단말에 작업 사본을 만들며 정상적으로 닫으면 삭제합니다.

공유 위치에서 여러 사용자가 같은 프로젝트를 동시에 편집하는 것을 방지하기 위해 프로젝트와 같은 위치에 임시 잠금 파일을 만듭니다. 이 파일에는 Windows 사용자 이름, 컴퓨터 이름, 프로세스 ID 및 시각이 포함되며 정상 종료 시 삭제됩니다.

.ploto 파일에는 Ploto 자체 암호화가 적용되지 않습니다. 업무상 기밀 정보를 저장하는 경우 조직의 규정에 따라 단말 암호화, 저장 위치 접근 권한, 공유 권한 및 백업을 설정하십시오. 저장 위치, 파일 이름 및 삭제 방법 등에 대한 자세한 내용은 정보시스템 부서용 기술 정보에서 확인할 수 있습니다.

3. 외부 서비스를 사용하는 경우

일반적인 프로젝트 생성, 편집 및 저장은 오프라인으로 할 수 있습니다. 사용자가 다음 작업 중 하나를 선택하면 외부 서비스가 필요한 정보를 처리합니다.

3.1. Microsoft Store 및 Windows

앱 배포, 업데이트, Store 내 구매 및 리뷰는 Microsoft Store에서 처리합니다. Windows와 Microsoft Store는 단말 및 조직의 설정에 따라 설치 정보, 오류 정보, OS 및 단말 진단 정보 등을 처리할 수 있습니다. Ploto 제공자는 개인을 직접 식별하지 않는 집계 정보를 품질 개선에 사용할 수 있습니다. Microsoft 개인정보처리방침이 적용됩니다.

3.2. 웹을 통한 Pro 라이선스 구매

웹 구매 시 Stripe는 구매자의 이메일 주소, 결제 수단, 구매 상품, 금액, 통화, 일시 및 연결 정보를 처리합니다. 카드 번호 등의 민감한 결제 정보는 Stripe가 직접 처리하며 Ploto 제공자의 서버에서는 취득하거나 저장하지 않습니다.

단말 연동 라이선스를 발급하기 위해 구매 시작 시 Windows가 게시자에게 제공하는 단말 식별 값에서 Ploto 전용 단방향 해시를 단말 내에서 생성하여 Stripe로 전송합니다. 원래 단말 식별 값은 전송하지 않습니다. Vercel에서 실행되는 처리가 라이선스 키를 발급하고 Resend가 구매자의 이메일 주소로 전송합니다. 구매 후 라이선스 확인은 단말 내에서 이루어집니다.

Stripe 개인정보 보호정책, Vercel Privacy Notice, Resend Privacy Policy가 각각 적용됩니다.

3.3. 문의 및 선택적 양식

사용자가 문의 이메일 또는 Google Forms를 제출한 경우 입력한 내용과 선택적으로 제공한 이메일 주소를 답변, 지원, 오류 조사 및 품질 개선에 사용합니다. 본 앱은 프로젝트 내용을 자동으로 첨부하거나 전송하지 않습니다. 조직의 허가 없이 기밀 정보, 개인정보, 프로젝트 파일 또는 화면 캡처를 전송하지 마십시오. Google 개인정보처리방침이 적용됩니다.

3.4. 공식 사이트 및 본 방침 열람

공식 사이트 ploto-app.com은 GitHub Pages를 통해 제공되며 Google Analytics 4를 사용합니다. 공식 사이트를 ?ga=off와 함께 열면 해당 브라우저에서 측정 태그를 불러오지 않도록 설정이 저장됩니다.

본 방침은 hiroking-ocean.github.io의 GitHub Pages를 통해 제공됩니다. 이 페이지에는 Ploto 자체 접근 분석을 설치하지 않으며 외부 웹 글꼴을 불러오지 않습니다. GitHub가 일반적인 접근 정보를 처리할 수 있습니다. 이 페이지가 브라우저에 저장하는 정보는 테마와 표시 언어 선택뿐입니다. GitHub General Privacy Statement가 적용됩니다.

4. 이용 목적 및 제3자에 의한 처리

Ploto 제공자가 구매, 문의, 선택적 양식 등을 통해 받은 정보는 라이선스 발급, 재전송 및 단말 연동, 부정 이용 방지, 결제와 지원 대응, 오류 조사, 품질 개선, 회계, 세무, 분쟁 대응 및 기타 법령 준수에 필요한 범위에서 사용합니다.

프로젝트 데이터, 구매자 정보 또는 문의 정보를 판매, 대여, 광고 제공 또는 데이터 브로커 제공에 사용하지 않습니다. 배포, 구매, 라이선스 발급, 이메일 발송, 양식 제출 및 웹 열람을 위해 필요한 범위에서 Microsoft, Stripe, Vercel, Resend, Google 및 GitHub가 정보를 처리합니다. 각 회사의 방침에 따라 대한민국 및 일본 외 국가나 지역을 포함하여 처리 또는 저장될 수 있습니다.

법령에 따른 경우, 사람의 생명·신체·재산 보호에 필요한 경우 또는 권리 보호와 부정 방지에 필요한 경우에는 적용 법령의 범위에서 관계 기관 등에 정보를 공개할 수 있습니다.

5. 보유 기간, 삭제 및 확인 등의 요청

구매 및 라이선스 정보는 라이선스 재표시와 재전송, 구매 지원, 부정 방지, 회계, 세무 및 기타 법령 준수에 필요한 기간 동안 보유합니다. 문의 및 양식 응답은 답변, 조사, 품질 개선 및 법령 준수에 필요한 기간 동안 보유합니다. 외부 사업자가 자체 목적을 위해 보유하는 정보의 기간은 각 회사의 방침에 따릅니다.

사용자가 저장한 프로젝트 등은 사용자가 삭제할 때까지 남습니다. 앱을 제거해도 사용자가 선택한 저장 위치의 파일과 일부 단말 내 보조 파일은 남습니다. 완전한 삭제 방법은 정보시스템 부서용 기술 정보를 확인하십시오.

Ploto 제공자가 보유하는 구매자 정보, 문의 정보 등의 확인, 정정, 이용 중지 또는 삭제를 원하는 경우 아래 연락처로 요청하십시오. 본인 확인 후 법령 또는 거래·라이선스 기록상 보유가 필요한 정보를 제외하고 합리적인 범위에서 대응합니다. 프로젝트 내용은 제공자가 보유하지 않으므로 제공자 측에서 공개, 복원 또는 삭제할 수 없습니다.

6. 변경 및 문의

본 방침을 변경하는 경우 이 페이지에 개정된 내용과 최종 수정일을 게시합니다. 정보의 종류, 이용 목적, 외부 전송 대상 등에 중요한 변경이 있는 경우 필요에 따라 앱 내 릴리스 노트 등으로도 안내합니다.
