Ploto는 사용자의 PC 내에서 모든 작업이 완결되는 데스크톱 앱입니다. 개인정보를 수집, 전송, 판매하지 않으며 프로젝트 데이터는 안전하게 사용자의 기기에 보관됩니다.

데이터 수집 제로

계정 가입 불필요. 분석 툴, 원격 측정(텔레메트리), 오류 자동 전송, 광고 추적기가 전혀 포함되어 있지 않습니다.

100% 로컬 저장

모든 프로젝트, 간트 차트, 칸반, 메모 및 설정은 PC 내부(.ploto SQLite) 또는 직접 지정한 사내 네트워크 드라이브에만 저장됩니다.

오프라인 서명 인증

Pro 라이선스는 Ed25519 암호화 서명 검증을 통해 기기 내에서 인증됩니다. 외부 서버와의 통신이 필요 없어 폐쇄망에서도 동작합니다.

투명한 외부 연계

Microsoft Store 배포, Stripe 결제 및 선택적 Google Forms 피드백과의 연동 방식을 투명하게 공개합니다.

1. 개요

Ploto("본 애플리케이션")는 Windows 환경에서 작동하는 프로젝트 관리 프로그램입니다. 간트 차트, 칸반 보드, 우선순위 매트릭스, 멤버별 업무, 노트, 화이트보드 등 다양한 기능을 제공하며, 사용자가 자신의 데이터를 완전히 통제할 수 있도록 설계되었습니다.

본 개인정보 처리방침은 데이터 처리에 대해 설명합니다. 요약하자면, Ploto는 개인정보를 수집하거나 프로젝트 데이터를 외부 서버로 전송하지 않습니다.

2. 수집하는 정보

수집하지 않습니다.

Ploto는 사용자 이름, 이메일, IP 주소, 위치, 기기 식별자, 작업 내용 등 어떠한 개인 데이터도 수집, 저장, 전송, 판매하지 않습니다.

앱 내에는 분석 도구(Google Analytics 등), 텔레메트리, 자동 크래시 리포터, 광고 트래커가 전혀 포함되어 있지 않으며, 회원가입이나 로그인 없이 즉시 사용할 수 있습니다.

3. 데이터의 저장 및 관리

생성된 모든 프로젝트, 작업, 간트 일정, 칸반 보드, 메모, ToDo, 템플릿(.ploto-pack) 등은 사용자의 기기 내부 또는 직접 지정한 공유 경로(사내 파일 서버, 네트워크 드라이브 등)에 .ploto(SQLite 형식)로 저장됩니다.

사용자가 직접 파일을 이동하거나 공유하지 않는 한 파일이 기기 외부로 나가지 않습니다. 개발자는 사용자 데이터를 수신, 보관, 처리하는 서버를 운영하지 않습니다.

4. 네트워크 이용 및 외부 서비스

Ploto는 완전한 오프라인 환경에서 동작하도록 설계되어 있으며 프로젝트 데이터를 네트워크로 전송하지 않습니다. 단, 플랫폼 기능 및 사용자가 직접 선택한 기능에서 다음 외부 서비스가 사용될 수 있습니다:

4.1. Microsoft Store (배포 및 업데이트)

앱 다운로드, 자동 업데이트 및 Microsoft Store를 통한 추가 기능 구매는 Microsoft 개인정보 처리방침의 적용을 받습니다.

4.2. Pro 라이선스 및 결제 (Stripe)

공식 웹사이트를 통한 라이선스 구매는 Stripe의 보안 결제 시스템을 통해 처리됩니다. 개발자는 신용카드 정보를 직접 수집하거나 보관하지 않습니다.

발급된 라이선스 키는 앱 내 Ed25519 암호화 서명 검증을 통해 완전 오프라인으로 인증됩니다. 인증을 위해 기기 정보나 통신 로그를 서버로 전송하지 않으므로 인터넷이 연결되지 않은 폐쇄망에서도 안전하게 작동합니다.

4.3. 피드백 및 설문조사 (Google Forms)

도움말 메뉴나 시작 화면에서 '의견 및 오류 신고'를 선택하면 기본 웹 브라우저에서 Google Forms 페이지가 열립니다.

참여 및 정보 입력은 전적으로 자율적이며, 사용자가 직접 입력한 내용만 Google 서버를 거쳐 개발자에게 전달됩니다(Google 개인정보처리방침 적용). 앱이 백그라운드에서 임의로 데이터를 전송하지 않습니다.

5. 제3자 제공

개발자는 프로젝트 데이터나 개인정보를 수집하거나 보유하지 않으므로, 어떠한 정보도 제3자에게 판매, 공유, 제공하지 않습니다.

6. 아동의 개인정보 보호

Ploto는 아동을 포함하여 누구로부터도 의도적으로 개인정보를 수집하지 않으며, 모든 연령층에서 안전하게 사용할 수 있습니다.

7. 처리방침의 변경

본 방침이 변경되는 경우, 새로운 최종 수정일과 함께 본 웹페이지에 개정판을 게시합니다.
