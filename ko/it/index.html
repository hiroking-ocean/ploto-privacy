1. 제품·문서 정보

본 문서는 Windows용 프로젝트 관리 애플리케이션 Ploto(이하 「본 앱」)에 대한 정보시스템 부서용 기술 정보입니다. 기업·단체의 앱 도입 심사에 이 페이지의 URL 또는 인쇄·PDF로 저장한 문서를 사용할 수 있습니다.

  • 제품명: Ploto
  • 지원 OS: Windows 10·Windows 11
  • 배포처: Microsoft Store
  • Microsoft Store 제품 ID: 9N4NJNMT2B77
  • 스토어 표시 게시자·제공자: hiroki.lab(개인 개발자)
  • 공식 사이트: https://ploto-app.com/
  • 문의처: hiroki.lab@outlook.com

본 앱을 업무 데이터에 사용할 수 있는지는 데이터의 기밀 등급, 단말·저장 위치의 접근 통제, 백업 및 조직의 앱 사용 기준을 고려하여 이용 조직이 최종적으로 판단해 주십시오.

2. 배포·실행 방식·권한

본 앱은 Rust, Tauri 및 Windows WebView2를 사용한 데스크톱 앱으로, Microsoft Store를 통해 MSIX로 배포·업데이트됩니다. 일반 실행 시 관리자 권한으로의 상승을 요구하지 않습니다.

MSIX 매니페스트에서는 데스크톱 앱으로 동작하기 위해 runFullTrust를 선언합니다. 이는 로그인한 사용자와 동일한 권한으로 동작한다는 의미이며, 관리자 권한을 자동으로 부여하는 것은 아닙니다. 본 앱은 Windows 서비스, 시작 프로그램 항목 또는 예약 작업을 만들지 않습니다.

3. Microsoft Defender·앱 제어 관련 주의사항

Microsoft Store에서 인증·배포된 앱이라도 조직의 단말에서는 Microsoft Defender 또는 애플리케이션 제어 설정에 따라 설치, 실행 또는 파일 저장이 차단될 수 있습니다. 본 앱은 Rust와 Tauri로 구현한 네이티브 실행 파일을 포함합니다. 이러한 구성의 앱은 배포 직후처럼 실행 실적(prevalence)이 적은 시기에 휴리스틱 탐지나 실적 기반 차단의 대상이 되기 쉬운 경향이 있습니다. 스토어 인증이 조직에서 설정한 이러한 제어를 면제해 주지는 않습니다.

예상되는 상황:

  • 백신의 휴리스틱 오탐: 클라우드 기반 머신러닝 판정으로 새 실행 파일이 Wacatac, Wacapew 등 일반적인 탐지 이름으로 격리되는 경우가 있습니다. 보안 인텔리전스 업데이트 후 해소되기도 합니다.
  • 공격 표면 감소(ASR) 규칙: 「실적, 사용 기간 또는 신뢰할 수 있는 목록 조건을 충족하지 않는 한 실행 파일 실행 차단」을 사용하도록 설정한 경우, 갓 공개된 버전이 차단될 수 있습니다.
  • 제어된 폴더 액세스: 문서, 바탕 화면 등 보호된 폴더에 대한 쓰기가 거부되어 .ploto 파일 저장 오류로 나타날 수 있습니다.
  • WDAC·AppLocker: 서명자 또는 패키지를 허용하지 않은 경우 MSIX 패키지가 아예 실행되지 않습니다.
  • SmartScreen: Microsoft Store를 통한 설치에서는 일반적으로 발생하지 않지만, 조직의 정책 설정에 따라 경고가 표시될 수 있습니다.

PackageFullName과 설치 경로는 버전마다 변경됩니다. 애플리케이션 제어 허용 규칙에는 경로가 아니라 위의 패키지 이름, PFN 및 게시자 정보를 사용하십시오.

조직에서 허용을 검토하는 경우:

  • WDAC·AppLocker: 설치된 패키지 또는 MSIX를 참조하여 Publisher와 Package name이 본 앱과 일치하는 패키지 규칙을 조직의 애플리케이션 제어 기준에 따라 만드십시오. 업데이트를 허용할 버전 범위도 조직의 변경 관리 정책에 따라 설정하십시오.
  • Microsoft Defender·ASR: 탐지 또는 차단이 발생하면 탐지 이름, 대상 파일, 입수 경로, 패키지 서명 및 관리 콘솔 기록을 확인하고 조직의 정해진 절차에 따라 대응하십시오. 보호 기능을 변경하거나 예외를 설정해야 한다고 판단한 경우 보안 관리자의 승인을 받아 본 앱에 한정된 최소 범위와 필요한 기간으로 제한하십시오.
  • 제어된 폴더 액세스: 저장이 거부되면 먼저 조직에서 허용한 저장 위치를 사용하십시오. 본 앱을 허용 목록에 등록해야 하는 경우 Microsoft Store에서 받은 패키지인지와 서명을 확인한 뒤 조직의 승인 절차를 따르십시오.
  • 오탐 신고: 탐지가 잘못되었다고 판단되면 Microsoft 샘플 제출 양식으로 신고할 수 있습니다. 탐지 이름, Defender 버전 및 본 앱의 버전을 아래 문의처로 알려 주시면 제공자 측에서도 신고합니다.

본 앱은 Windows 서비스, 시작 프로그램 항목 및 예약 작업을 만들지 않습니다(제2항 참조). 따라서 탐지가 발생한 경우 휴리스틱에 의한 오탐일 가능성이 높지만, 실제 처리는 조직의 보안 운영 기준에 따라 판단해 주십시오.

4. 파일 접근

기술적으로는 실행 사용자가 접근 권한을 가진 파일을 읽고 쓸 수 있습니다. 제품 기능으로 다루는 대상은 사용자가 열기·저장·가져오기·내보내기 대상으로 선택한 파일, 본 앱의 단말 내 설정·작업 파일, 그리고 동시 편집 방지를 위한 잠금 파일입니다.

단말 내 파일을 전수 조사하는 기능, 임의의 폴더를 지속적으로 감시하는 기능, 프로젝트 파일을 외부로 자동 업로드하는 기능은 없습니다. 저장 위치에 대한 읽기·쓰기 권한은 Windows 및 파일 서버의 접근 통제를 따릅니다.

5. 저장되는 파일과 정보

프로젝트: 사용자가 지정한 위치에 .ploto 파일로 저장합니다. 형식은 표준 SQLite 데이터베이스이며 작업, 담당자 이름, 일정, 할 일, 노트, 화이트보드, 설정 등이 포함됩니다. 템플릿, 가져오기 원본 및 Excel 등의 출력 파일도 사용자가 선택한 위치에서 읽고 씁니다.

작업 사본: 프로젝트를 여는 동안 프로젝트 전체의 작업 사본을 Windows가 관리하는 앱 로컬 데이터 영역에 만듭니다. 정상적으로 닫으면 삭제하며, 비정상 종료로 남은 사본은 다음 실행 시 삭제를 시도합니다.

잠금 파일: 편집 중에는 프로젝트와 같은 위치에 대상 .ploto 파일 이름.lock 파일을 만듭니다. Windows 사용자 이름, 컴퓨터 이름, 프로세스 ID, 시작 시각 및 갱신 시각을 저장하며 정상 종료 시 삭제합니다. 공유 폴더에서는 해당 위치에 접근할 수 있는 사용자 또는 관리자가 확인할 수 있습니다.

단말 내 설정: UI 설정, 라이선스 키, 안내 표시 상태, 편집자 설정 등을 Windows가 관리하는 본 앱의 로컬 데이터 영역에 저장합니다. 최근에 연 파일은 %USERPROFILE%\.ploto\recent-files.json에 최대 10건의 경로와 최종 접근 일시를 저장합니다. 일부 보조 설정 파일은 %USERPROFILE%\.ploto에 저장합니다. 프로젝트를 만든 설치본을 판별하기 위한 무작위 식별 값을 저장하는 경우가 있습니다. 이 값에는 OS의 단말 식별 정보나 개인정보가 포함되지 않으며 외부로 전송하지 않습니다.

6. 네트워크 통신과 허용 목록 후보

프로젝트의 작성·편집·저장 및 구매한 라이선스의 검증에 인터넷 연결은 필요하지 않습니다. 앱 내 WebView에는 외부 사이트에 접속하지 않도록 Content Security Policy를 설정하고 있습니다. 외부 페이지는 사용자의 조작에 따라 기본 웹 브라우저 또는 Microsoft Store에서 열립니다.

조직에서 통신을 제한하는 경우 주요 연결 대상 후보는 apps.microsoft.com(제품·리뷰), buy.stripe.com·checkout.stripe.com(웹 구매), ploto-v2-license-webhook.vercel.app(구매 완료·연결 확인), docs.google.com(선택 양식), ploto-app.com(공식 사이트), hiroking-ocean.github.io(매뉴얼·본 문서)입니다. 각 서비스의 CDN, 인증, 글꼴 등 부수 도메인은 각 사업자의 사양에 따릅니다.

Windows Update, Microsoft Store, Windows 오류 보고 등에 의한 OS·플랫폼 통신은 단말 및 조직의 Microsoft 제품 설정을 따릅니다.

7. 외부 서비스와 전송 정보

Microsoft: 앱의 배포, 업데이트, 스토어 내 구매, 리뷰 및 OS 진단을 처리합니다. Ploto 제공자는 Partner Center에서 집계된 배포·품질 정보를 확인하는 경우가 있습니다.

Stripe: 사용자가 웹 구매를 시작한 경우 결제 정보, 구매자 이메일 주소, 상품·금액·통화·일시, 연결 정보 및 개인정보 처리방침 제3.2항의 단말 해시를 처리합니다. 카드 번호 등은 Stripe가 직접 처리합니다.

Vercel: Stripe의 구매 완료 정보를 받아 서명된 라이선스 키를 생성합니다. 구매자용 자체 데이터베이스는 두고 있지 않으나 운영 로그가 처리되는 경우가 있습니다.

Resend: 구매자의 이메일 주소로 라이선스 키를 발송하며 수신처, 본문 및 발송 정보를 처리합니다.

Google: 사용자가 선택 양식을 제출한 경우 응답 내용 등을 처리합니다. 공식 사이트에서는 Google Analytics 4를 사용합니다. 본 앱 자체에는 Google Analytics를 포함하지 않습니다.

GitHub: GitHub Pages로 공식 사이트, 매뉴얼 및 본 문서를 제공하며 표준적인 접근 정보를 처리하는 경우가 있습니다.

8. 암호화·인증·안전 관리

.ploto, 작업 사본 및 잠금 파일에는 Ploto 자체의 저장 시 암호화를 적용하지 않습니다. 기밀 정보를 다루는 경우 BitLocker·EFS 등의 OS 기능, 저장 위치 ACL, 공유 권한, 백업, 반출 통제 등을 조직 측에서 설정해 주십시오.

Pro 라이선스는 Ed25519 전자 서명을 단말 내에서 검증합니다. 이는 라이선스 키의 정당성을 확인하는 것이며 프로젝트를 암호화하는 기능은 아닙니다. 웹 구매용 결제 정보는 Stripe가 호스팅하는 화면에서 입력하며, 라이선스 발급 Webhook은 Stripe의 서명을 검증한 후 처리합니다. 비밀 키 및 외부 서비스의 API 키는 앱 자체에 포함하지 않습니다.

이용 조직에서는 최소 권한의 Windows 계정, 단말 암호화, 저장 위치 접근 통제, 백업, 악성코드 대책, OS·스토어 앱 업데이트, 외부 양식에 대한 기밀 정보 입력 제한 등을 시행해 주십시오.

9. 제거와 잔존 데이터

Microsoft Store 버전을 제거하면 Windows가 관리하는 본 앱의 로컬 데이터 영역은 일반적으로 삭제됩니다. 반면 사용자가 지정한 저장 위치의 프로젝트, 템플릿, 가져오기 원본, 출력 파일 및 %USERPROFILE%\.ploto는 삭제되지 않습니다. 완전히 삭제하려면 필요한 백업을 확인한 후 사용자 또는 단말 관리자가 삭제해 주십시오.

비정상 종료나 접근 권한 문제로 작업 사본 또는 잠금 파일이 남는 경우가 있습니다. 잠금 파일은 아무도 해당 프로젝트를 편집 중이 아님을 확인한 후 삭제해 주십시오.
